NOSSA PLATAFORMA

Sobre a ENOVA 💛

A ENOVA é uma plataforma educacional criada para ajudar estudantes na preparação para o Exame Nacional do Ensino Médio.

Nosso objetivo é tornar a prática de questões mais acessível, organizada e divertida, permitindo que estudantes revisem conteúdos e conheçam questões de provas anteriores.

Tecnologias utilizadas

HTML, CSS, JavaScript e API pública ENEM.dev.

Fonte das questões

API ENEM.dev, com dados públicos de provas anteriores.
